멘토링 요약은 한국어 음성인식 전사와 영상 화면을 대조해 작성했으며, 시간은 녹화본의 재생 위치입니다. 2차 영상 표지는 2026-11-04, 3차는 2026-11-06입니다. 3차 요약에는 사용자가 제시한 게시판 질문 네 개와 영상 답변의 대응 구간도 정리했습니다.

첨부 HTML·PDF는 `materials/`에 원본 그대로 보존했습니다. 변환본은 표·코드·페이지 순서를 살렸고, 주요 도식과 장비 사진은 `docs/materials/assets/`에 수록했습니다. PDF의 원문 이용 고지도 변환본에 보존했습니다.

문서별 작성 시점이 달라 예전 M1 예시의 `sectors`·`goal_base`와 API 안내의 `search_sectors`·`base`처럼 서로 다른 표기가 있습니다. 변환본은 원문 값을 유지하고 불일치를 별도 메모로 표시했습니다. API 안내는 **2026-11-04 기준 스냅숏**이며, 3차 영상에서는 **본선 오리엔테이션 당일 최종 API 문서 재배포**를 안내합니다.
